## Исправленные дефекты

- PDF сайта скрывал название курса и не соответствовал представленному образцу.
- Итоговый тест был обязательным в редакторе независимо от признака сертификата; учебный интерфейс всегда показывал вкладку тестирования.
- Варианты с несколькими правильными ответами и короткие ответы отсутствовали. Теперь оценку считает БД, ключи не передаются студенту.

- При занятом порте Express 5 передавал ошибку в callback, который её игнорировал и сообщал об успешном запуске. Ошибка теперь видна и процесс завершается с ненулевым кодом. Vite использует строгий порт.

## Границы проверки

Полный сценарий с реальными admin/student аккаунтами, обновлённым удалённым Supabase, Storage и доставкой писем требует применения SQL и отдельных тестовых пользователей. Удалённые изменения оставлены пользователю по его просьбе. Нагрузочные проверки и конкурентные транзакции через отдельные PostgreSQL-соединения не запускались: нет настроенного disposable PostgreSQL/Docker. PGlite и HTTP-проверки не заменяют такой тест.

Проверка сигнатуры загружаемого файла не является антивирусом; ограничения запросов в памяти процесса требуют внешнего ограничения трафика при нескольких backend-процессах. Публичная проверка сертификата раскрывает ФИО и название обладателю непредсказуемого номера — это существующая функция сервиса. ФИО вводит сам участник, проверка личности не реализована. Уже скачанный PDF невозможно дистанционно отозвать; актуальный статус показывает QR/страница проверки.

В Git уже отслеживается `node_modules` (6851 файл). Для будущей публикации репозитория целесообразно отдельно убрать зависимости из индекса, сохранив `package-lock.json`; в рамках этой работы индекс не менялся. `.env` не отслеживается, клиентские переменные проверены на отсутствие серверных ключей. Deployment-шаблоны HTTPS/proxy и настройки Auth/SMTP требуют проверки на реальном сервере.

При проверке правил функций и доступа использована официальная документация: [Database Functions](https://supabase.com/docs/guides/database/functions), [Row Level Security](https://supabase.com/docs/guides/database/postgres/row-level-security), [API keys](https://supabase.com/docs/guides/getting-started/api-keys). Пустой `search_path`, явные права вызова и закрытые серверные ключи сохранены.
