# Рабочее задание

Проверить существующий React/Express/Supabase проект, запустить приложение и доступные проверки. Основной сценарий — обучение на семинарах. Сохранить стиль и структуру сайта, вносить только необходимые изменения интерфейса.

1. Проверить границы доверия: роли, RLS, RPC, серверный расчёт результатов, доступ к правильным ответам, загрузки, выдачу и публичную проверку сертификатов. Исправлять подтверждённые дефекты, не обещать абсолютную безопасность.
2. При создании/редактировании семинара дать явный выбор итогового теста. С тестом — сертификат после ознакомления с материалами и успешной сдачи; без теста — завершение обучения без сертификата. Отображать это в каталоге, деталях и обучении. Запрет выдачи должен действовать в БД, а не только в интерфейсе.
3. Поддержать один ответ, несколько правильных ответов, верно/неверно и короткий текстовый ответ. Обеспечить валидацию редактора и БД, секретность ключей, совместимость старых тестов и незавершённых попыток. Для нескольких ответов засчитывать только точное совпадение набора; для текста — совпадение с допустимыми вариантами без учёта регистра и лишних пробелов.
4. Использовать приложенный образец только как визуальный ориентир. Создать рабочий PDF с реальными ФИО, названием семинара, академическими часами, датой, организацией, существующим изображением подписи, номером и QR на проверку конкретного сертификата. Сохранять снимок данных при выдаче и не менять ранее сохранённые PDF.
5. Подготовить SQL для ручного применения пользователем в Supabase. Не изменять удалённую БД. Проверить новую схему и миграцию локально, включая повторное применение и сохранение истории.
6. Проверить сборку, lint, тесты безопасности и сценарии новых вопросов/семинаров. Запустить сайт, проверить доступный интерфейс и визуально проверить PDF. Записать реальные результаты и ограничения; дать конкретную инструкцию применения SQL.

Критерии: сертификат невозможно получить без итогового теста и проходного результата; правильные ответы не доступны студенту; все типы вопросов сохраняются и оцениваются сервером; семинар без теста можно завершить; действующие сертификаты и история не теряются.
