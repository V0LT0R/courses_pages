# 2.0.0

- Перенос новой выдачи сертификатов из отдельной БД в Supabase; атомарный issue_certificate, immutable snapshots, уникальность user/course, публичный безопасный ответ и список сертификатов в кабинете.
- Сохранение PDF в PostgreSQL, одинаковые байты повторной загрузки, встроенный DejaVu Serif с лицензией, длинные ФИО/названия и QR, без часов. Визуальный стиль с синей/золотой рамкой сохранён.
- Устранение optional optimistic token, защиты от удаления прогресса, роли NULL, timestamp до ожидания блокировки; audit и история курса.
- Серверная проверка загрузок; закрытие прямой записи в Storage; пакетная выдача signed URLs вместо запроса на каждый блок.
- Единый Supabase Auth; удалены неиспользуемые локальные users/login/JWT/seed API и фиктивные credential/blockchain поля. Создание менеджеров перенесено с Edge Function в проверенный Express endpoint.
- Очистка private кеша при смене сессии; учёт пользователя в ключе кеша; защита асинхронной загрузки учебной страницы; ErrorBoundary, восстановление пароля, понятные сообщения.
- Каталог: 12 курсов на страницу; тяжёлые страницы подгружаются по маршруту.
- Обновлены React Router до 7.18.3 и Vite до 8.3.0, устранены известные уязвимости зависимостей; react-is согласован с React 18.
- Lockfile использует публичный npm registry; SQL-файлы генерируются из единого набора исходников; повторяемая миграция и read-only проверка PASS/FAIL.
- Тесты поведения PostgreSQL/API/PDF, отдельные реальные конкурентные соединения, k6, инструкции Windows/Linux и пример reverse proxy.

Совместимость: неиспользуемые локальные /api/auth/*, /api/seminars/* и multipart /api/uploads/pdf больше не обслуживаются. React из этого архива их не использует. Старая deployed Edge Function должна быть удалена. Старые SQL filenames содержат явное сообщение о замене, чтобы случайно не восстановить уязвимые права.
