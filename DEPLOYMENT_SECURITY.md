# Защита развёртывания

Приложение не обеспечивает защиту от объёмного DDoS само по себе. Express имеет лимиты запросов, размеров тела (64 KiB JSON; 25 MiB файлы), времени запросов, 4 одновременных загрузок и 4 генераций PDF на процесс. Один сертификат в рамках процесса генерируется единственным Promise; между процессами побеждает первая запись PDF по PRIMARY KEY.

Лимитер находится в памяти: он сбрасывается при рестарте и не является общим для реплик. Для нескольких экземпляров нужен общий лимитер на reverse proxy/API gateway (например Redis) и предел реплик/соединений. Не увеличивайте число процессов без оценки памяти и нагрузки на Supabase.

На периметре:

- HTTPS, CDN/WAF, управляемая защита от DDoS и ботов; origin должен быть доступен только через доверенный прокси.
- Node слушает 127.0.0.1. При контейнеризации HOST=0.0.0.0 допустим только внутри закрытой сети.
- `TRUST_PROXY=1` допустим лишь когда единственный путь к Node проходит ровно через один доверенный прокси. При Cloudflare + Nginx настройте real_ip в Nginx по официальным адресам Cloudflare; не доверяйте произвольному X-Forwarded-For.
- Ограничьте размер HTTP тела, число соединений и запросов на `/api/uploads`, `/api/certificates`, `/verify`. Сверяйте лимиты с нагрузочными измерениями.
- `/readiness` проверяет версию SQL; он не заменяет ежедневные резервные копии и внешнее наблюдение за ошибками Auth/Storage.
- `/verify` и `/api` имеют `Cache-Control: no-store`; не переопределяйте это кеширующим правилом CDN. Статические хешированные JS/CSS можно кешировать год.

**Supabase доступен напрямую из браузера.** WAF перед Node не защищает Supabase REST/Auth/Storage. RLS, ограничения таблиц и RPC защищают данные при обходе Node. В Supabase отдельно включите подтверждение email, CAPTCHA, Auth rate limits, надёжный SMTP, лимиты запросов и мониторинг квот. Антибот-настройки и доступные ограничения зависят от вашего тарифа. У теста есть серверное ограничение: 10 новых попыток за скользящие 24 часа на пользователя и курс; активная попытка при повторном запросе возвращается без расходования лимита.

Проверка сигнатуры файла исключает простое переименование HTML в PDF, но не заменяет антивирус/проверку сложного содержимого. Для файлов от недоверенных преподавателей нужен отдельный карантин и сканирование перед публикацией. Текущий сервер разрешает загрузку только admin/manager, запрещает HTML/SVG и не исполняет/не распаковывает загруженное содержимое. Signed URL — временный bearer-доступ: его получатель может поделиться ссылкой до истечения часа. Немедленное аннулирование уже выданной ссылки не обещается.

CSP Express предназначена для страниц проверки сертификатов, а не для React. CSP React задаётся на хостинге с точным Supabase-доменом, Google Forms/Sheets, YouTube и фактическими доменами изображений. Сначала проверьте её в Report-Only, затем включите enforcement. Не используйте `unsafe-eval` и не добавляйте произвольные скриптовые домены. Проверка CORS не является авторизацией: запросы без Origin всё равно проходят проверку JWT/RLS.
